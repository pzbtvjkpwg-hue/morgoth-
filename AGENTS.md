# Общие правила ChatGPT и Claude

Перед работой прочитать актуальный main, последние коммиты, PROJECT.md, HANDOFF.md, CHANGELOG.md и BUGS.md. Активная игра — duo/index.html (Three.js), версия 2.1.1 на момент создания документа. Владелец сам создаёт анимации. Не переносить движок без запроса. Перед изменением игры создать snapshot-ветку для отката, работать в отдельной ветке, проверить актуальность main перед объединением. Не удалять функции и не нарушать совместимость анимаций, ригов, карт и пресетов. Каждому игровому обновлению присваивать номер версии; документация не меняет номер игры. После каждой задачи обновлять HANDOFF.md и CHANGELOG.md, при необходимости PROJECT.md и BUGS.md. Указывать автора, изменения, проверки, незавершённые задачи и откат. Не делать force push. Не публиковать секреты и пользовательские экспорты. Не заявлять о тестах, которые не проведены. GitHub — общая память обоих ИИ.

## Обязательное правило публикации
По прямому требованию владельца: все пункты команды реализовать в отдельной ветке до публикации игрового кода в main. Проверить совместимость и доступные тесты, сообщить о непроверенных пунктах и блокерах до публикации. Незавершённые или промежуточные обновления публиковать только с явного разрешения владельца. Правило действует для ChatGPT и Claude.
